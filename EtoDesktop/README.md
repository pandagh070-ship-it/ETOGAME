# Eto Desktop

Windows 7-friendly desktop customization prototype.

Features:
- Image wallpaper
- Animated GIF wallpaper
- Video wallpaper using the Windows MediaElement stack
- Lightweight replacement taskbar
- Digital clock
- Restores the original Windows taskbar when the app closes

Target: .NET Framework 4.8 / WPF.

Note: Windows 7 must be SP1. Video playback depends on the codecs available on the machine.
